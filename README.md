# piggy bank - для финансовых целей.
 Помогает ставить цели по накоплению, отслеживать прогресс, пополнять/списывать средства, назначать сроки и получать напоминания. Данные хранятся в JSON.
## Возможности

- Добавление целей: название, целевая сумма, категория.
- Отслеживание прогресса: процент и визуальный бар.
- Изменение баланса: пополнение и частичное списание.
- Назначение срока: вручную или с прогнозом даты.
- Напоминания: предупреждение, если срок наступил, а цель не выполнена.
- Удаление целей и сводка по всем целям.
